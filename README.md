# Skyline Riot

**v0.1 concept prototype** — motorised **Sky Treks**, rooftop lines, rail grinds, wall rides, and graffiti tags.

Inspired by the energy of Air Gear and Jet Set Radio, with **original characters, names, and setting only**.

## Play

**[Play Skyline Riot →](https://tomokifaizuru.github.io/skyline-riot/)**

Mobile-first (touch stick + JUMP / TAG / BOOST). Keyboard on PC.

## Concept

| | |
|---|---|
| **Name** | Skyline Riot |
| **Hook** | Rival crews race across Harbor Heights on motorised inline Sky Treks. Tag every district marker before dawn — combos charge your Air Dash. |
| **Core loop** | Skate → grind / wall-ride / air trick → fill boost → tag spots → clear the block |

## Controls

| Action | Keyboard | Touch |
|--------|----------|-------|
| Move | WASD / arrows | Left stick |
| Jump (hold higher) | Space | JUMP |
| Air trick | Space again / Q / E | JUMP in air |
| Boost (Air Dash) | Shift | BOOST |
| Tag | F | TAG |
| Pause | Esc / P | ⏸ |

## Tech

- Three.js r128 (CDN), single-page, no build step
- Cel-shaded `MeshToonMaterial` + inverted-hull outlines
- WebAudio placeholder funk loop (real track later)

## Version

`v0.1` — small city block, 6 tag spots, 90s timer.
